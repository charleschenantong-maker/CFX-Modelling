| 中文术语 | English | 一句话解释（含形状/默认值/失败模式，可含 LaTeX） |
|---|---|---|
| 倒数排名融合 | Reciprocal rank fusion (RRF) | 只按名次融合多路检索结果，单个结果贡献 \(1/(\kappa+\mathrm{rank})\)，常数常取 60；无需两路分数可比，代价是丢失分差信息。 |
| 父子块检索 | Parent-child retrieval | 用小子块建索引保证召回精度，命中后改送它所属的大父块给生成模型；父块常取 1600–2000 token，避免答案被切碎在块边界。 |
| 上下文预算 | Context budget | 把窗口按区段预先分配：系统指令与输出 schema 属不可压缩区，检索块按融合分数从低到高先砍，并留约 10% 余量给格式开销。 |
| 硬负例 | Hard negative | 与查询相似但不含答案的文档，用于训练或评估检索器；只喂随机负例时模型学不会区分，Recall@k 会被明显高估。 |
| 引用支持率 | Citation support rate | 被引段落真正支持所标注句子的比例；它与引用 id 合法率是两个指标，前者需判定式校验，混用会低估风险并修错地方。 |
| 全文索引 | Full-text search index (FTS) | 为词项建倒排表以支持 BM25 之类打分；SQLite FTS5 自 3.9.0（2015-10-14）内置并自带 bm25() 排名，适合单机语料。 |
