# _glossary/ —— 新增术语的来源记录

这里的 `17.md` … `24.md`、`G.md` 是 v1.2 为高阶章与附录 G 新增术语时的**交付草稿**，
每条已被合并进 [附录 A 术语表](../content/90-appendix-a-glossary.js) 第 15 节（表格末尾那一组）。

保留它们的原因有两个：

1. **可回溯**：附录 A 里某条术语如果被改错，可以在这里对照原始措辞。
2. **可复用**：以后再加新章时，直接照这个格式写术语，然后用
   `node tools/merge-glossary.mjs` 合并进附录 A（脚本会做 Markdown 表行 → HTML `<tr>` 的转换）。

格式（3 列，表头逐字一致）：

```markdown
| 中文术语 | English | 一句话解释（含形状/默认值/失败模式，可含 LaTeX） |
|---|---|---|
| 投机解码 | Speculative decoding | 用小草稿模型连猜 k 个 token，再由目标模型一次前向并行验证；接受率越高加速越多。 |
```

要求：中文 2–8 字；解释 30–80 字，必须含可检验信息（公式 / 默认值 / 规模 / 失败模式之一）；
公式用 `\( \)` 且公式内不得有中文；先搜附录 A 确认不重复。
