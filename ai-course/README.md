## 这是什么？

一份写给**好奇的人**的大模型入门材料。它回答的是那些最常被跳过、却最要紧的问题：

- 模型说它「预测下一个词」，可这到底是什么意思？
- 训练一个模型，屏幕上到底在算什么？为什么会「炸」？
- 那些名词——注意力、参数、微调、对齐、量化、显存——各自指哪一件事？
- 为什么有人说「$20 的订阅比充值 API 划算」？算给谁看？

和大多数教程不同，这门课：

| 特点 | 意味着什么 |
|---|---|
| **离线可用** | 数学公式渲染器和字体都打包在仓库里，断网也能读 |
| **可通读，也可当手册** | 第一遍按顺序读；之后用搜索或附录速查表随手查 |
| **不假设你什么都会** | 有专门的「预备课」，从概率和梯度讲起，全部手算 |
| **数字尽量给你来源** | 关键数据标注了官方出处与核对日期，而不是「据说」 |

## 30 秒开始

1. **下载这个仓库**（右上角 `Code → Download ZIP`，或 `git clone`）
2. 打开 `ai-course` 文件夹，**双击 `index.html`**
3. 从左侧目录的 **「预备课 P」** 开始读；零基础也建议从这里进

> 如果你的浏览器对本地文件限制较严，在 `ai-course` 目录下运行 `python -m http.server 8000`，
> 然后访问 `http://localhost:8000/` 即可。

**想让学习进度存进本地文件？**（而不是只存在浏览器里）

```bash
cd ai-course
python progress_server.py        # 然后打开它打印的 http://127.0.0.1:8000/
```

这样页面会把进度**自动写进同目录的 `progress.json`**（已读章节、自测成绩、学习时长）。
不想跑脚本也没关系：左下角有「选文件夹」（浏览器直接写你选的文件夹）、「导出 / 导入」两种兜底方式。

**不需要**：安装 Python 环境、注册账号、联网、显卡（进度落盘功能可选）。

## 你会学到什么

课程分成六个部分，加六个附录。按顺序读即可，每章 20–60 分钟。

| 部分 | 章节 | 一句话 |
|---|---|---|
| **导览** | 00 | 怎么用这份材料、你手上的资源怎么分工 |
| **预备课** | P | 概率、神经网络、损失、梯度下降——全部手算一遍 |
| **一 · 底座** | 01–05 | 模型在算什么、文字怎么变成数字、注意力与 Transformer、预训练全流程 |
| **二 · 训练与推理** | 06–09 | 多卡怎么协作、微调与对齐（SFT/DPO/GRPO）、怎么部署省钱、怎么证明「真的变好了」 |

| **四 · 现实世界** | 11–15 | 订阅额度怎么算、网络与账号、任务配额、多线程工作流、硬件瓶颈 |
| **五 · 收束** | 16 | 把学到的接回一个真实的数学建模项目 |
| **六 · 高阶与前沿** | 17–24 | **蒸馏**全谱系、推理模型与测试时计算、**RAG 与上下文工程**、智能体系统、安全与可解释性、**机器意识**、压缩与模型合并、前沿架构与多模态。v1.2 起每章都有：可复算的手算例子、失败模式表、30 分钟最小实现，以及「用在你自己的项目上值不值」的判断 |
| **附录** | A–G | 术语表（355 条）、8 个实验手册、资源地图、合规提醒、综合自测、**速查手册**、**AI 素养课地图（22 门官方课 + 厂商中立检查表）** |

## 三种用法

| 你想做什么 | 大概要多久 | 怎么做 |
|---|---|---|
| **完整通读一遍** | 6–12 小时 | 按 00 → P → 01 → … → 16 顺序读，每章末尾做自测 |
| **随手查一个东西** | 1–3 分钟 | 顶部搜索框（快捷键 `/`），或翻 **附录 F 速查手册**（公式/数字/超参/命令/排错表） |
| **动手跑一个实验** | 每个 30–90 分钟 | 去 **附录 B**，8 个实验都写在免费 Colab 上能跑完的规模 |

**三个最值得先看的入口：**

1. 完全零基础 → **预备课 P**（手把手，含手算示例）
2. 想直接查数据与公式 → **附录 F · 速查手册**
3. 想今天就跑出结果 → **附录 B 的 E7**（不需要 GPU，直接产出可用于研究的统计结论）

**另外两个「不是技术、但决定你能不能坚持下去」的入口：**

4. 想搞清「AI 素养」到底指什么、官方那批免费课该怎么用 → **附录 G · AI 素养课地图**
   （22 门课按四组编好，逐门标注适合谁 / 学完能做什么 / 对应本课程哪一章；核心是那张**厂商中立检查表**：
   学的是可迁移的能力，不是某一家产品的按钮。）
5. 想把「和模型协作」变成能被验收的流程 → 附录 G 的 4D 框架 + 模块 09 的评估方法

## 常见问题

**要联网吗？**
读课不用。仓库里的公式渲染器和 20 个字体文件都是本地文件，断网照常显示。只有做 Colab 实验时需要联网。

**要显卡吗？**
读课不需要。附录 B 的实验按免费 Colab 的额度设计（约 30–90 分钟一个），个别实验纯 CPU 也能跑。

**要什么基础？**
会一点 Python 更顺，但所有代码都配了说明。数学只需要高中水平——用到导数、对数、求和符号时都会重新解释一遍直观含义。

**额度、价格这些信息会过期吗？**
会。这部分内容标注了**官方出处和核对日期**，并且明确区分了不同订阅档位（网上流传的数字常常是最高档的，不适用于 $20 档）。请以官方页面为你账户显示的数值为准。

**能打印或导出 PDF 吗？**
可以。右上角「打印」按钮会自动展开所有折叠内容，直接导出成 PDF 慢慢看。

**可以改内容吗？**
可以。课程就是普通的 HTML + JS 文件，`ai-course/content/` 下每个 `.js` 是一章，改完刷新页面即可。

**学习进度存在哪里？会不会丢？**
默认存在浏览器的 localStorage 里（刷新不丢，但换浏览器或清缓存会丢）。想更稳妥有三种方式：
① 运行 `python progress_server.py`，进度会自动写进 `ai-course/progress.json`；
② 点左下角「选文件夹」，让浏览器直接写进你指定的目录（Chrome / Edge）；
③ 用「导出 / 导入」手动保存成 JSON。
进度里包含：已读章节、每章自测的对错数、累计学习时长。

node ai-course/tools/validate.mjs          # 内容结构自检（0 error 才算过）

- 每个 `content/*.js` 都能被 `vm` 载入，且 `COURSE.register` 元数据完整
